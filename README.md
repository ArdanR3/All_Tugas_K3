# All_Tugas_K3

Proyek simulasi **K3 (Keselamatan dan Kesehatan Kerja)** berbasis **Unity 6 (`6000.6.0f1`)** dengan dukungan **XR / VR** dan aset 3D **Blender**.

## 🛠️ Tech Stack
- **Engine:** Unity `6000.6.0f1` (URP)
- **XR / VR:** Unity XR Interaction Toolkit & XR Hands
- **3D Modeling:** Blender
- **Language:** C#

## 📁 Struktur Utama
- `Assets/00_Scenes` — Scene utama proyek
- `Assets/01_Scripts` — Script C# gameplay & simulasi
- `Assets/07_XR` — Konfigurasi XR/VR
- `Assets/08_UI` — Aset dan layout UI
- `Assets/10_K3_Simulation` — Aset & modul simulasi K3
- `Packages/` & `ProjectSettings/` — Konfigurasi package dan project Unity

## 🚀 Cara Membuka Proyek
1. Clone repository ini:
   ```bash
   git clone https://github.com/ArdanR3/All_Tugas_K3.git
   ```
2. Buka folder proyek melalui **Unity Hub** menggunakan Unity versi **`6000.6.0f1`**.
3. Tunggu Unity melakukan *re-import* folder `Library/` secara otomatis.
